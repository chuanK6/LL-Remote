# 统一组件初始化

LL 主程序仅启动固定清单内的组件。被控角色由用户在应用内开启；Sunshine 便携进程不额外注册自启动入口。已有服务由用户选择复用，应用不会重新安装或覆盖已有配对。

主程序启动清单请求 Windows 管理员权限，皎月连网络宿主继承该权限。已有 Sunshine Windows 服务的操作由专用入口处理固定的 SunshineService。账号密码通过本机 HTTPS 接口验证，不传给权限组件。

网络宿主为固定版本皎月连 SDK 接入原生 Wintun 数值诊断，记录写入对应 Data 的 wintun-error.json。SDK 身份和内存布局必须全部匹配才替换它的可选日志初始化回调。Rust 按当前宿主 PID、操作开始时间和初始化阶段校验报告；清理阶段日志不会冒充网卡创建失败。
