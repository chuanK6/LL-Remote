# 0.1.14 导航与壁纸缩略图调整候选 · 2026-11-25

按用户明确的界面要求，移除「全部设备」入口和表格页面，保留设备资料、连接记录、收藏及配对。在线主机继续从侧栏「我的设备」进入；桌面默认入口、登录完成和旧 `/devices` 地址转向开始协助，首次使用引导保留。

连接记录和收藏列表左侧改为设备壁纸缩略图，宽窗口为 116×76，较小窗口适当缩小。没有自定义壁纸或读取失败时显示默认壁纸；各条记录和收藏仍读取同一设备资料，修改壁纸后同步更新。

版本号保持 0.1.14。本轮只构建与包校验，待用户查看实际运行效果，未运行单元、网页、桌面或内核测试。当前公开 GitHub 资源仍为此前验收的壁纸重连修正版。
