LL远程 0.1.12 Windows x64 便携版，整合皎月连组网、Sunshine 被控端和 Moonlight 串流控制端。

## 下载与运行

下载下方的 `LLRemote-Portable-x64-0.1.12.zip`，完整解压后运行其中的 `LLRemote.exe`，按提示接受 Windows 管理员授权。首次使用完成 Sunshine 账号设置和皎月连登录。

应用使用系统 Microsoft Edge WebView2 Runtime；未安装时会提示打开微软安装页。下载包不包含发布者的 Data、登录凭据、配对私钥和浏览器缓存，首次运行会创建自己的 Data。

## 本版本更新

- 增加“始终接受控制”，可使用已保存凭据在启动时开启服务；手动开启显示进度。
- 连接前刷新对端状态，托盘支持断开串流或当前组网，并显示失败原因。
- 改善窗口、全屏和无边框模式切换与窗口大小恢复。
- 首次配对填写设备名，默认 `roth` 可修改。
- 通用、组件常用和会话设置即时保存，调整防休眠和开机登录任务。

支持同账号设备连接和识别码协助。识别码连接需要被控端提供识别码、连接密码及组网地址；首次串流需要 PIN 配对，后续复用有效证书。

第三方许可证与对应 Moonlight/Sunshine 源码归档位于包内 `notices`。项目源码、使用说明和版本记录见本仓库 README 与 docs。更广泛 Windows 环境、多屏及长期运行验证将继续完善。

同名 `.sha256.txt` 附件用于核对下载完整性。
