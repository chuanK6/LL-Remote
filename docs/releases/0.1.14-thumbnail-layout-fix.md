# 0.1.14 列表缩略图定位修正候选 · 2026-11-25

用户反馈此前候选的壁纸覆盖整行，挡住设备名称、连接信息和时间。要求只把列表左侧的电脑图标替换成壁纸缩略图，保留其余内容与布局。

原因是复用的壁纸图片继承详情页的绝对定位，而缩略图容器没有限定其定位范围。此次仅修正共用列表中的定位：图片恢复正常文档流，并限定在左侧缩略图框内；名称、连接方式、识别码、备注、时间、详情箭头和删除按钮沿用原有布局。连接记录和收藏同时生效，自定义与默认壁纸继续共用。

版本保持 0.1.14，沿用已移除「全部设备」入口和页面、保留设备资料的调整。只做类型检查、生产构建、生成 CSS 检查及包校验，不运行单元、网页、桌面或内核测试。保留个人 Data、配置和配对，更新本机 release 后清理临时输出；新修正版运行效果待用户验收，公开 GitHub 资源保持此前版本。详见 `docs/validation/0.1.14-thumbnail-layout-fix.json`。
