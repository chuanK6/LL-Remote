# LL远程 v0.1.16

## 本次更新

- **应用内签到**。首次登录或旧版资料缺少截止日期时，会提示打开签到页。软件按账号保存官网的服务到期时间和下次可签到时间，并用系统时间计算剩余服务时长。剩余两小时以内时，签到按钮显示黄色。
- **IP 直连**。两台电脑使用同一个便携包。被控端开启直连，控制端填写对方的 IP 和可选端口。用户已验证局域网连接正常。公网直连尚无实测环境。[连接说明](https://github.com/chuanK6/LL-Remote/blob/v0.1.16/docs/连接流程与组网地址.md#ip-直连)
- **自定义快捷键**。在「设置 → 快捷键」可以修改或恢复默认。`Ctrl+Alt+Shift+Z` 捕获或释放鼠标，`Ctrl+Alt+Shift+D` 断开当前连接，`Ctrl+Alt+Shift+L` 切换本机显示器常亮。组合键在主界面或远控窗口获得焦点时生效。
- **在线设备和记录**。同账号在线列表随皎月连目录更新主机名，备注跟随已识别的设备。连接记录支持单条删除，收藏页的删除按钮移除整台设备及其连接记录。

## 升级

先从托盘完全退出旧版，再完整解压 `LLRemote-Portable-x64-0.1.16.zip`。需要沿用账号、配对和设置时，将旧版完整的 `Data` 复制到新版 `LLRemote.exe` 同级目录。请保留旧版目录或 Data 副本。更换电脑或 Windows 用户后，加密凭据需要重新认证。

用户反馈，沿用旧版 Data 时偶尔会遇到兼容问题。若遇到问题，可保留原资料，另解压一份便携包，用随包的空 `Data` 排查。首次连接需要重新 PIN 配对。远程升级前，请确认能通过其他方式操作被控机。如果空 Data 下仍无法直连，可检查 Windows 防火墙中仍指向已移除程序路径的旧规则，保留当前路径和其他应用的规则。

## 已知问题

- 部分台式机在显示器熄屏后首次连接可能出现黑屏。可临时在被控端开启「设置 → 电源与屏幕 → 保持显示器常亮」。
- 用户观察到同一被控端同时使用 UU 远程与 LL远程时也可能出现黑屏。遇到黑屏可按 `Ctrl+Alt+Shift+D` 断开，再单独使用 LL远程重连。这两种黑屏的具体触发原因仍待定位。
