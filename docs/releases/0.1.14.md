# LL远程 0.1.14 · Windows x64 便携版

首次发布日期：2026-11-24；同版本修正更新：2026-11-25。版本号保持 0.1.14。

## 本版解决的问题

- **同账号设备设置壁纸后，离线重连壁纸消失**：修正皎月连目录 ID 变化后原设备资料没有衔接的问题。原壁纸文件仍存在时沿用原引用，保留收藏、设置及全部连接记录。目录名称唯一、旧 ID 未被其他在线设备使用且已确认身份无冲突时衔接资料，连接继续核对已保存的 Sunshine UUID。
- **同一设备的多个连接记录和收藏详情没有共用壁纸**：在线详情、同设备全部连接记录详情和收藏详情使用同一份设备资料。在任一入口更换壁纸或恢复默认并保存，其他入口一起更新，不把每条连接记录当作一台主机。

- **两端同时接受控制、组网地址相同导致无法连接**：通用设置增加默认关闭的「自动切换角色」。地址冲突时可开启功能，暂时暂停本机接受控制后连接；远控结束并清理后至少等待 3 秒，确认没有串流进程、内部重连或客户端组网连接，再恢复本机接受控制。调整画质引起的内部重连保持暂停，手动停止本机服务或退出会撤销自动恢复。
- **移动旧 Data 后，验证 Sunshine 账号会重新创建 0.1.12 目录**：随包 Sunshine 启动时更新旧的账号状态、应用、证书和日志绝对路径，使用新版目录中的 Data，保留已保存的账号和配对。
- **连接后悬浮球不显示、默认全屏难以操作本机**：会话悬浮窗口复用主窗口 WebView2 环境，在界面线程创建并优先显示。新连接默认窗口模式，会话内可切换全屏，画质重连保持当前会话模式。
- **性能监测出现在宿主屏幕右下角**：卡片改为跟随 Moonlight 客户区右下角，随窗口移动、缩放和 DPI 更新，最小化时隐藏。性能监测默认关闭，关闭时不创建卡片窗口。
- **我的设备混入断开后的历史主机，出现很多重复名字**：「我的设备」和全部设备页仅显示当前皎月连账号目录的在线主机。在「开始协助」下方增加独立「连接记录」，按时间倒序显示可悬浮高亮的列表卡片，支持搜索、详情及返回，不显示主机在线状态。没有详细连接时间的旧资料标为「时间未记录」。
- **收藏藏在编辑弹窗中、列表样式不一致**：设备名右侧增加五角星按钮，点击立即收藏，变为黄色并提示「已收藏设备」。收藏列表与连接记录使用相同卡片布局。
- **删除设备后还留下连接记录或从恢复备份重新出现**：两个列表悬停显示删除按钮，点击直接删除对应主机资料、收藏及全部历史，无二次确认、无软删除。主数据和恢复备份同步清理，无其他引用的受管理连接授权和自定义图片删除；默认图、来源文件和其他设备共享的资料保留。资料已不存在的历史不再显示。

继续保留 0.1.13 的壁纸显示修复、单张图片最大 5 MB、恢复/更换图片后的旧副本清理、默认关闭到托盘及码率按钮每次 1 Mbps。

## 升级前请保存 Data

1. 从旧版托盘菜单选择「完全退出」。关闭窗口默认只进入托盘，不能代替完全退出。
2. **先保存旧版程序旁完整的 `Data` 文件夹**，建议复制一份备份。不要只保存 `preferences.json`，设备记录、收藏、账号授权和配对等资料也在 Data 中。
3. 完整解压新版便携 ZIP，将旧版 `Data` 复制到新版 `LLRemote.exe` 同级目录，替换下载包中的空 Data。目录应为 `LLRemote-Portable-x64-0.1.14/Data`，避免多套一层 `Data/Data`。
4. 在同一台电脑、同一个 Windows 用户下运行新版，已有配置和配对可继续使用，无需重新配置；随包 Sunshine 的旧目录路径会自动调整。

更换电脑或 Windows 用户时，加密凭据受 Windows DPAPI 绑定限制，需要重新认证。公开下载包的 Data 为空，不包含发布者个人数据。
