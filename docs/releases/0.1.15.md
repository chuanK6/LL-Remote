# LL远程 0.1.15 · Windows x64 便携版

发布日期：2026-11-25。

本版整理此前同版本候选中的导航与列表调整。用户已确认修正后的功能测试通过，现升级为 0.1.15。

## 本版变化

- 移除「全部设备」入口和表格页面，保留设备资料、连接记录、收藏及配对。在线主机继续从侧栏「我的设备」进入，收藏保留独立页面。
- 连接记录和收藏仅将左侧电脑图标替换为设备壁纸缩略图，保留名称、连接方式、识别码、备注和时间。修正图片覆盖整行的问题；无自定义壁纸或加载失败时显示默认图。同一设备的详情、历史和收藏继续共用壁纸。
- 默认首页、登录完成及删除设备后的跳转进入「开始协助」，旧 `/devices` 地址兼容跳转，首次使用引导保留。

继续保留此前的壁纸离线重连修复、设备资料与历史管理、自动切换角色、悬浮球修正、新连接默认窗口模式、系统共享 WebView2，以及已保存的配置和配对。

## 升级步骤

1. 从旧版托盘选择「完全退出」，关闭主窗口默认只进入托盘。
2. 保存旧版程序旁完整的 `Data` 文件夹，账号、设备、收藏、画质和配对等资料均在其中，不要只保存一个配置文件。
3. 完整解压 `LLRemote-Portable-x64-0.1.15.zip`，将旧 `Data` 放到新版 `LLRemote.exe` 同级目录，替换包内的空 Data，避免套成 `Data/Data`。
4. 在同一电脑、同一 Windows 用户下启动新版，已有资料和配对可继续使用。随包 Sunshine 的受管理路径会在启动时调整。

更换电脑或 Windows 用户时，DPAPI 加密凭据需要重新认证。下载包不含发布者个人 Data、配置、凭据或配对。

## 附件与验证

- `LLRemote-Portable-x64-0.1.15.zip`：完整 Windows x64 便携包，含三个内核及依赖，使用系统共享 WebView2。
- `LLRemote-Portable-x64-0.1.15.zip.sha256.txt`：ZIP 的 SHA-256 校验值。
- `LLRemote-0.1.15-release-notes.md`：本说明及升级步骤。

功能验收来自用户对修正后的 0.1.14 候选的反馈「功能测试通过」。0.1.15 沿用该功能代码，更新版本配置后重新构建，校验程序资源与干净 ZIP；未重新运行单元、网页、桌面或内核测试，未提供逐项环境矩阵。对应记录见 `docs/validation/0.1.15.json`。
